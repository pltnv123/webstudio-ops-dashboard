# Copy Review — V4.9

## Weak copy found
- Root was good after V4.8, but still read like a general dashboard rather than an owner/client review path.
- Pricing route is safe, but needs approved assumptions before it becomes sales copy.
- Order Builder and Website Page Builder remain more internal than client-facing.

## Stronger replacement copy applied
- Root journey: “turns a client request into a reviewable product journey”.
- Boundary: “explicit about what is demo-only versus what needs owner approval before live use”.
- Added Owner Review / Next Revisions CTA and route.

## CTA improvements
- Root CTAs now include owner review before live usage.
- Public navigation includes `/owner-review/` as a safe review checkpoint.
- Owner Review route links to demo order, client handoff, pricing, route health.

## Claims to avoid
- Guaranteed leads, revenue, rankings, conversion rate, medical/legal outcomes.
- Fake testimonials, unverified logos, fabricated case studies.
- Fixed price/time claims before scope, inputs, assumptions, and owner approval.
- Any wording implying live CRM/email/Telegram/payment/database writes are enabled.
