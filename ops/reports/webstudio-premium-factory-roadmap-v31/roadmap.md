# Premium Website Factory Roadmap v3.1

1. Client interview: sanitized intake creates structured order.
2. Design system selection: choose premium style family, tokens, layout primitives, motion level.
3. Page generation: home, service, proof/case studies, about, contact, optional landing variants.
4. QA checklist: responsive, accessibility, broken links, console, performance, copy/proof labels.
5. Deploy preview: static preview with client-safe demo data first.
6. Delivery report: screenshots, checks, unresolved approvals, next action.
