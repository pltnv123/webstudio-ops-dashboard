# Acceptance Criteria

- Demo-only client order JSON exists and validates as structured data.
- Production brief has offer, audience, pages, proof policy, conversion goal.
- Premium package has sitemap/copy/design/component/SEO/conversion/QA docs.
- Dashboard route shows pilot order/package status from sanitized static snapshot.
- Build, smoke, local static route, and secret scan pass.
- GitHub branch push preserves verified local SHA via host bridge.
- Public Pages route returns HTTP 200.
- Supabase job/artifact/status rows are written with sanitized metadata.
