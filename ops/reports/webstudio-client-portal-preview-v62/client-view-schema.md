# Client view schema

- `project_summary`: label, package, current status, preview link, next milestone.
- `required_assets`: item/status/owner_action.
- `approval_checklist`: item/status/owner_action.
- `revision_requests`: item/status/owner_action.
- `timeline`: item/status/owner_action.
- `links`: safe related public routes.
- `safety`: static/read-only/no-login/no-writes flags.
