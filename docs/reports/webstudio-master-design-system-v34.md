# WebStudio Premium Design System

## Brand voice
Спокойная уверенность. Дорогая студийность без крика. Конкретика вместо “AI-powered” шума. Клиент видит: стратегия, визуалы, motion, QA, handoff.

## Typography
- Headlines: editorial serif or high-end grotesk; large, tight tracking, controlled line-height.
- Body: readable sans, 16–18px, generous leading.
- Numbers/proof: tabular digits, small caps labels.

## Colors
- Base: warm ivory `#F7F0E7`, pearl `#FFFDF8`, ink `#2B241E`.
- Premium accents: bronze `#A06D45`, moss `#7E8F86`, clinical blue-gray `#6E7F99`.
- Healthcare mode: lower saturation, high contrast, no aggressive red except warnings.

## Spacing and layout
- Mobile-first; desktop max width 1180–1280px.
- Sections breathe: 80–140px desktop, 48–80px mobile.
- Use asymmetric editorial grids; no template wall of cards.

## Premium cards
- Hairline border, warm canvas, subtle shadow, rounded 24–34px.
- One visible hierarchy: label → heading → proof/action.
- No raw technical/debug labels in client-facing surfaces.

## CTA rules
- One primary CTA per viewport.
- Secondary CTA supports trust, not distraction.
- Healthcare CTA uses consultation language, not guaranteed result.

## Trust/proof blocks
- Real proof > generated concept.
- If not verified, mark as planned/generated.
- Doctors/certificates/cases require approval before publication.

## Image rules
- Business-specific art direction per industry.
- No cheap generic stock look.
- Concept visuals are allowed only with explicit classification.

## Motion rules
- Motion guides attention; never hides content.
- Default: opacity/transform reveal, short duration, reduced-motion branch.
- Video/WebGL require fallback and performance budget.

## Accessibility
- Contrast, keyboard focus, semantic headings, labels, reduced motion, pause controls.

## Anti-template rules
- Avoid blue/purple SaaS gradients by default.
- Avoid fake logos/testimonials/metrics.
- Avoid identical sections across concepts.

## Industry variants
### Dentistry / medicine
Clinical calm, real doctors, documents, consented cases, careful wording, no guarantees.
### Architecture / interior
Material texture, spatial photography, project timelines, case studies.
### SaaS / AI
Product UI proof, workflow diagrams, metrics only if verified, restrained motion.
### Beauty / luxury
Editorial photography, service rituals, premium booking path, no exaggerated outcomes.
### Legal / expert services
Authority, cases anonymized, credentials, risk-safe copy, document clarity.
### Local services
Location trust, reviews, process, pricing ranges where safe, fast mobile CTA.
