# WebStudio Premium Factory Tooling Map v34

## Production core
- HTML/CSS/JS static preview: default client proof.
- Python/Node build tooling: snapshots, smoke, schema validation.
- DESIGN.md + JSON tokens: visual source of truth.
- SVG/Canvas visuals: safe concept layer when real assets absent.
- GSAP: premium micro-motion and reveal timelines.
- HyperFrames: deterministic website-to-video path through isolated render worker.
- Browser QA: visual proof + console checks.
- GitHub Auto-Push / Host Runner: branch + PR automation.

## Conditional tools
- React/Vite/Next: when component reuse/app complexity justifies it.
- Three.js/R3F/WebGL: only for business-specific spatial value; always fallback.
- Lottie: for lightweight approved brand animations.
- FFmpeg: video metadata/transcode/poster extraction.
- Playwright: screenshots/visual regression when environment supports it.

## Reference-only until reviewed
- `awesome-agent-skills` external skills;
- Anthropic document skills with separate license terms;
- arbitrary Open Design marketplace packages;
- external design systems with brand/trademark risk.

## Tool policy
- Use simplest stack that reaches premium quality.
- No complexity theater.
- No real client proof without approval.
- No medical trackers by default.
- No MP4 PASS without actual render + metadata proof.
