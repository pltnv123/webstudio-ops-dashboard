# Client Example #002 Strategy

Updated: 2026-05-24T21:26:06Z

## Positioning
Премиальная стоматология для пациентов, которые выбирают не «самую дешёвую имплантацию», а безопасный план лечения, врачей с понятной экспертизой и ощущение дорогой, спокойной клиники.

## Core offer
Консультация по имплантации и винирам с понятным планом, диагностикой и персональным куратором.

## Audience
- Москва, средний+ и высокий чек.
- Пациенты 30–60, которым важны эстетика, безопасность и отсутствие давления.
- Самые выгодные клиенты: комплексные планы лечения, имплантация, виниры, повторные визиты семьи.

## Objections
- Страшно / больно.
- Не доверяю клиникам.
- Боюсь скрытых платежей.
- Не понимаю, какой врач нужен.

## Trust blocks
- Врачи и специализация.
- Диагностический маршрут.
- Кейсы с разрешением.
- Прозрачный план лечения.
- Safety/proof policy.
