# Client #004 D2 Telegram Intake Flow v30

## Guardrail
Бот не ставит диагноз, не обещает результат, не хранит медицинские данные сверх согласованного минимума.

## Flow
1. Выбор услуги: имплантация / виниры / консультация / не уверен
2. Уточнение цели и срочности
3. Наличие снимков/заключений — только факт наличия, без загрузки в демо
4. Удобное время и контакт
5. Handoff менеджеру клиники

## Escalation
Боль, осложнения, срочный медицинский вопрос → рекомендация связаться с клиникой/врачом; бот не консультирует.
