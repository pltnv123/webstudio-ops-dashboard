# WebStudio Mobile App Roadmap v34

## Why later
Mobile app is useful after website factory stabilizes: intake, order tracking, approvals, previews, artifact library, chat with agents, notifications, payments later.

## Candidate stacks
- React Native / Expo: fastest WebStudio reuse, JS ecosystem.
- Flutter: polished UI/performance, separate skillset.
- Native: later only if needed.

## Must be stable first
- interview schema;
- asset registry;
- approval gates;
- artifact library;
- client preview/handoff;
- payment/legal boundaries.
