# Adaptive Interview Script v32

Start with the 10-question short intake. Do not overwhelm the client. Branch only after answers:
- high-check service → proof, trust, objections, legal wording
- visual-sensitive service → photography, atmosphere, brand references
- automation requested → Telegram/CRM/data/privacy gates
- motion requested → hero video, social teaser, reduced-motion fallback

Confirmation closes with: summary, selected package, what we build, what client provides, approval gates.
