# Premium Image Direction v31

- status: PASS

## Direction
Images should feel like a private clinic editorial shoot: soft daylight, mineral textures, doctor hands, calm interiors, real documents. No cheap stock, no exaggerated smiles, no fake procedure photos.

## Asset classes
- Hero: real clinic interior + doctor presence, calm and expensive.
- Doctors: portraits with context, not passport photos.
- Certificates: photographed documents with legible but privacy-safe details.
- Cases: process/story layout, no unsupported result claims.
- Telegram journey: refined UI mock, no patient data.
