# Asset Legitimacy Model v34

## Classes
- real_client_asset: supplied/approved by client.
- official_reference: from verified official channel; approval may still be required.
- licensed_stock: license documented.
- generated_concept: design-only, not factual proof.
- planned_shoot: shotlist target, not present yet.
- placeholder: temporary and must be replaced.
- forbidden_unverified: must not be used publicly.

## Rule
Every visual must carry status, source, usage rights, where used, approval required, replacement needed.
