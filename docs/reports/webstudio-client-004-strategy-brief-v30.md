# Client #004 Strategy Brief v30

## Positioning
Премиальная стоматология без агрессивных обещаний: экспертность врачей, прозрачный путь консультации, доказательства через документы/кейсы/подход, спокойный премиальный визуал.

## Conversion logic
1. Спокойный hero: имплантация и виниры без давления.
2. Trust stack: врачи, сертификаты, технологии, процесс диагностики.
3. Case-safe section: формат кейса без гарантии результата.
4. Telegram CTA: консультация/запись с передачей менеджеру.
5. Medical boundary: информация не заменяет очный приём.
